# ZRG Roleplay — oficjalny launcher

Minecraft **1.20.1**, Forge **47.4.10**, serwer **zrgroleplayedition35.gmhst.pl**.

## Pobierz i graj

**[Pobierz ZRG Launcher 1.0.2 dla Windows](https://github.com/kacperwojtasiak12-web/zrg-roleplay-paczka/releases/download/pack-1.0.0/ZRG-Launcher-1.0.2.exe)**

1. Uruchom pobrany plik EXE. Launcher wymaga Java 17.
2. Poczekaj na automatyczne pobranie i sprawdzenie paczki. Pierwsze pobranie to około 1,3 GB; pliki Minecrafta są pobierane dodatkowo z oficjalnych źródeł.
3. Wpisz swój nick i naciśnij **Graj teraz**.

Jeśli wcześniej używałeś lokalnej wersji, wybierz **Wersje gry → Paczka serwera online**. Przy kolejnych otwarciach launcher pobiera tylko zmienione mody lub grupy zasobów. Postęp jest widoczny w aplikacji. Po zmianie nazwy gracza serwer traktuje go jako inną lokalną tożsamość.

## Aktualizacje

[Wydania paczki i opisy zmian](https://github.com/kacperwojtasiak12-web/zrg-roleplay-paczka/releases)

Paczka zawiera 78 modów, konfigurację oraz zasoby potrzebne klientowi ZRG Roleplay. Sumy SHA-256 zabezpieczają pobieranie przed uszkodzeniem plików. Światy i osobiste dane gracza nie są częścią publikacji.

Nie pobieraj ręcznie plików o długich nazwach z sekcji Assets — launcher sam umieszcza je we właściwych folderach. Nie jest potrzebne konto GitHub.

Launcher korzysta z wpisanego nicku, bez logowania Microsoft. Serwer musi dopuszczać taki sposób połączenia. Aplikacja nie jest podpisana certyfikatem wydawcy.
